# Road-map v3.3

## 1. Поиск: вся выдача + проверка «качества»
- [x] Аудит: бот читал страницы `sort:score`, но Gelbooru не отдаёт глубже 20 000 постов
      (`pid*limit`, «Too deep»). Всё, что глубже, было недоступно, а упор давал «некорректная выдача».
- [x] Курсор за потолком: `score:N` + `id:<…` (`sort:id:desc`), затем `score:<N sort:score`.
- [x] Распознавание ответа «Too deep» как отдельной ошибки → автоматический переход на курсор.
- [x] Аудит «качества»: score работает — сайт сортирует по нему (`sort:score`), локально он
      третий ключ после strict (нагота) и тира фокуса. Плюс локальный отсев трешака
      (`lowres`, `sketch`, `jpeg_artifacts`…). Живая сверка на Safebooru: топ бота = топ сайта.
- [x] Safebooru: HTTP 404 при всплеске запросов = лимит с повтором.

## 2. Приоритетные теги (фокус части тела)
- [x] Аудит: ранжирование правильное, но ранняя остановка игнорировала тир — бот брал
      «любые 5 новых» с 1-й страницы, даже если там фокус на другой части тела.
- [x] Доказанная остановка: читаем дальше, пока не найдено 5 новых с макс. тиром и
      score ≥ последнего прочитанного (лучше них в непрочитанной части нет).
- [x] Сверка с сайтом: алиасы (`boobs` → `breasts`) сайт разрешает сам; для не-телесных
      тегов порядок бота совпадает с `sort:score` сайта.
- [ ] Решение владельца: `foot_focus` в блэклисте, но он же — фокус-тег группы `feet`
      (группа почти не работает). `feet_focus` на сайте почти не встречается.
